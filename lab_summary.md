The main challenge was coordinating multiple external services without making the app fragile or expensive. I (+Codex!) solved this by validating environment configuration, normalizing NewsAPI responses, adding simple rate limits, tracking estimated token costs, using fallback logic between OpenAI and Anthropic, caching repeated articles, storing processed results in SQLite, adding analytics, and supporting scheduled and emailed reports. I learned how provider-specific APIs can be wrapped behind a cleaner application workflow, and a future improvement would be deploying the Flask UI so non-technical users can run reports from a browser.
I decided not to test the Multi Provider - was not that interesting to me =).
