The main challenge was coordinating multiple external services without making the app fragile or expensive. I (+Codex!) solved this by validating environment configuration, normalizing NewsAPI responses, adding simple rate limits, tracking estimated token costs, and using fallback logic between OpenAI and Anthropic. I learned how provider-specific APIs can be wrapped behind a cleaner application workflow, and a future improvement would be adding caching or SQLite storage so repeated articles do not need to be processed again.
